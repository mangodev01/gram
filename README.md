# gram

nice and simple, easy-to-use, somewhat fast cli-based telegram client

## REPL mode
to enter REPL mode, just run `gram` with no arguments.

## normal mode
to use normal mode, just run `gram` with whatever single command you wanna give it.

## config
the gram config is stored in <config path for your system>/gram/conf.toml,
if you modify it, gram will automatically catch that and refresh itself,
so any changes you do should be applied (almost) instantly (in most case-scenarios)
